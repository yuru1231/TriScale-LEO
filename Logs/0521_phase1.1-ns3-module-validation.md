## Path Loss 驗算（user 0）

User 0 位於原點 `[0, 0, 0]`，衛星在 `[25.68, 0, 600000]`。

```
d = sqrt(25.68² + 0² + 600000²) ≈ 600000.0006 m

FSPL (f=30 GHz, d=600 km):
  = 20·log10(4π · 600000 · 30e9 / 3e8)
  = 20·log10(4π · 6e7)
  ≈ 177.54 dB

Atmospheric loss (90° elevation, zenith scaling):
  ≈ 0.39 dB

Total path_loss ≈ 177.93 dB
ns3 module output  = 177.925 dB  ✅
```

## Phase 1.2 — Nadir-Shadow Design & ns3 Event-Driven Mode


## Background

Phase 1.2 將 simulation 架構改為 **nadir-shadow**，讓局部座標原點隨衛星移動，對齊 SNS3 的 `create_basic_ground_station_for_satellite_shadow()`（gid=-1）行為，並新增 ns3 event-driven 執行模式。

---

## Changes

### 1. `sat-multi-beam-geometry.cc / .h` — 新增兩個函式

| 函式 | 作用 |
|---|---|
| `GetSatellitePositionAtTime(timeS, cfg)` | 從時間 T（秒）直接計算衛星在弧軌跡上的 Cartesian 位置，取代 frame index lookup |
| `GetNadirFromTime(timeS, cfg, latDeg, lonDeg)` | 計算 T 時刻的衛星 nadir（sub-satellite point）地理位置（緯度、經度） |

`GetSatellitePositionAtTime` 轉換公式：
```
eps(T) = eps_zero + (T / t_frame) * d_eps
x_sat  = R * cos(eps)
z_sat  = R * sin(eps) − r_earth
y_sat  = 0
```

### 2. `sat-multi-beam-simulation.cc` — Nadir-shadow 重設計

**核心設計變更：**

| 項目 | Phase 1.1（舊） | Phase 1.2（新） |
|---|---|---|
| 局部座標原點 | 固定 footprint center（Tokyo 35.68°N, 139.65°E） | 動態 nadir（每個時間步更新） |
| 衛星位置（局部 frame） | `arcPos[frameIdx]`（隨 frame 變化） | 固定 `{0, 0, h_satellite}`（always在正上方） |
| CLI 參數 | `--frame 38537,33090,23932`（整數 frame index） | `--time-s 385.37,330.90,239.32`（秒，浮點數） |
| CSV 欄位 | `frame_id, elevation_deg` | `nadir_lat_deg, nadir_lon_deg` |
| JSON 欄位 | `elevation_angle`（變化值） | `time_s`, `nadir_lat_deg`, `nadir_lon_deg`; `elevation_angle` 固定 90.0 |
| 輸出檔名 | `results_{frame}_{footprint}km.json` | `results_{time_ms}ms_{footprint}km.json` |

### 3. 新增 ns3 event-driven 執行模式

#### Phase 1.2.1 — `--mode=nadir`（Nadir-shadow continuous mode）

```
struct NadirSimState { cfg, userPos, beamCenters, satCsv, chanCsv, rng, updateMs, endTimeS }

NadirUpdateStep:
  1. t = Simulator::Now()
  2. GetNadirFromTime(t) → (latNadir, lonNadir)
  3. localCfg.center = (latNadir, lonNadir); satPos = {0, 0, h}
  4. ComputeFrameResults → AppendChannelCsvRows
  5. Simulator::Schedule(updateMs, NadirUpdateStep)
```

輸出：`satellite_positions.csv`、`channl_results.csv`

#### Phase 1.2.2 — `--mode=arc`（Arc pass mode）

```
struct ArcSimState { cfg, userPos, beamCenters, satCsv, chanCsv, rng, updateMs, minElevDeg, ... }

ArcUpdateStep:
  1. t = Simulator::Now()
  2. satPos = GetSatellitePositionAtTime(t) → elevDeg = GetElevationAngleDeg(satPos)
  3. Write arc_satellite_positions.csv（全程記錄，含低仰角）
  4. if elevDeg >= minElevDeg: ComputeFrameResults → AppendArcChannelCsvRows
  5. Simulator::Schedule(updateMs, ArcUpdateStep)
  6. 結束時寫出 arc_summary.json
```

輸出：`arc_satellite_positions.csv`、`arc_summary.json`

# Fix — Grid User Cap

## Description

執行 Phase 1.2 驗證時，發現：

- `user_positions.csv` 達到 6.5 MB
- `channel_results.csv` 超過 3 GB

原因：`GetGridUserPositions(500m spacing, 100km footprint)` 產生約 **122,004 users**。

---

## Root Cause

### Bug 1 — resize 條件嚴格（`sat-multi-beam-simulation.cc`）

舊版 resize 只在 `nadir` / `arc` mode 觸發：

```cpp
// 舊：macro mode 完全不 cap
if ((mode == "nadir" || mode == "arc") && requestedNUser < userPos.size())
{
    userPos.resize(requestedNUser);
}
```

`--mode=macro`（預設）完全跳過 resize → 122k users 全部寫入。

### Bug 2 — `nUser` 預設值 1000（`sat-multi-beam-config.h`）

即使 nadir/arc 的 resize 觸發，預設 `nUser=1000` 在全 pass（774s / 0.1s = 7740 steps）下仍產生：

```
7740 steps × 1000 users × ~90 bytes/row ≈ 697 MB
```

---

## Fix

### `sat-multi-beam-simulation.cc`

移除 mode 限制：

```cpp
// 新：所有non rician mode 都 --n-user cap
if (requestedNUser < static_cast<uint32_t>(userPos.size()))
{
    std::cout << "  (capped from " << userPos.size()
              << " to " << requestedNUser << " users via --n-user)\n";
    userPos.resize(requestedNUser);
}
```

### `sat-multi-beam-config.h`

`nUser` 預設值改為 `1e9`（等效無上限），避免意外 cap 大格點驗證：

```cpp
// 舊
int nUser{1000};

// 新
int nUser{static_cast<int>(1e9)};  // cap disabled by default
```

---

## Behavior After Fix

| 指令 | 修正前 | 修正後 |
|---|---|---|
| `--mode=macro --n-user=37` | 忽略 37，產生 122k users | cap 到 37 users ✅ |
| `--mode=nadir --n-user=37` | resize 37 | resize 37 ✅ |
| `--mode=macro`（無 `--n-user`） | 122k users | 122k users（無變化，Full validation 用） |
| `--mode=nadir`（無 `--n-user`） | resize 到 1000 | 122k users（應顯式傳 `--n-user=37`） |
